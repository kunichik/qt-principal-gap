QTimeZone: Reject all-dot components in isValidId()

isValidId() accepted an id component made entirely of dots, including
"..". No IANA/POSIX zone database uses such name, and ".." is a parent
directory reference that a zone id should never contain.

Track the dot count per component alongside its length and reject any
component that is all dots. Components that merely contain a dot are
unaffected.
